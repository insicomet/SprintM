# SprintM

Инженерный веб-калькулятор ангаров ИНСИ «Спринт М». Стек: React 18, TypeScript, Vite и Vitest. Основной код находится в `src/`, расчётная логика — в `src/calc/`, исходные и подготовленные справочники — в `data/` и `src/data/`, скрипты извлечения и Excel-эталон — в `scripts/`.

## Работа с проектом

- Рабочая ветка: `claude/start-session-l3r43f`; перед изменениями проверяй `git status` и текущий diff.
- Excel-книги и справочные данные являются источниками истины для расчётной логики. Не меняй формулы или правила подбора без проверки паритета с исходными таблицами.
- Расчётную логику держи вне React-компонентов; UI должен собирать ввод, вызывать расчёт и отображать результат.
- Сохраняй существующие русские подписи и явно показывай состояния отсутствия данных или допустимого решения.
- Не коммить локальные Excel-файлы, секреты, `.env`, `node_modules` и результаты временных проверок.

## Проверка

После изменения расчётов запускай целевые тесты, затем полный набор:

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
```

Если изменение связано с Excel, дополнительно используй сценарии из `scripts/oracle/` и фиксируй проверенные входы и расхождения. Готово означает, что тесты и сборка прошли, а изменение не нарушило подтверждённый Excel-паритет.
